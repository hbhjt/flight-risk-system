# M4 集成验收

日期：2026-11-16。四个页面均使用真实半年统计或六月评分。

## 功能

P3提供机场、航司、日期、计划时刻联动，显示同一真实航班的四模型分数、推荐B3的阈值和历史样本支持数。实际结果默认隐藏，更改航班后重置隐藏。固定20个案例覆盖TP、FP、FN、TN，展示时不提前泄漏类别。范围为六月未取消、未备降的已评分航班，历史截至四月。

P4提供全部测试指标、PR曲线、可切换模型的可靠性图与混淆矩阵、同参数验证比较，以及按机场、小时、历史支持数的错误分析。页面明确未校准分数和样本选择限制。

## 验证

新增API测试使用独立合成数据库，覆盖默认隐藏/主动揭示、联动选项、真实记录查询、非法ID和非法日期。普通测试7项通过，2项JVM测试跳过；JVM边界测试已在M3实际执行通过。前端生产构建通过。

Playwright实际浏览器检查1366×768、1920×1080：切换日期后评分刷新且实际结果重新隐藏；展开后可以看到真实误判；切换B1后可靠性图和混淆矩阵同步；错误分组切换为历史支持数成功。最终生产构建控制台0错误0警告。截图见images/m4-risk.png及images/m4-experiments.png。

独立停止并重启API后，health、根页面、dashboard、experiments、risk/options和favicon均实测HTTP200。重启没有重新训练或重新启动Spark，发布数据库可独立演示。

## 使用限制

单台Windows上的WSL2伪分布式HDFS与单机Standalone，不是多机部署。风险仅用于历史条件回测，未实现实时天气、取消预测或面向任意未来航班的服务。模型效果提升及局限沿用M3验收结论，不扩大训练预算。
