# 基于 Spark 的航空航班延误分析与风险预测系统

版本：1.1。定稿日期：2026-11-16。本文是实施与验收依据；完成状态以 implementation_plan.md 和实际运行产物为准。本次修订补充全流程协作与GitHub交付责任。

## 1 目标与课程对应

使用美国 BTS 官方航班记录，完成采集、HDFS 存储、Spark 处理、机器学习、网页交互和可复现实验。回答三个问题：机场及航线的延误规律是什么；历史特征能否改善预测；存储格式如何影响查询性能。

教师要求包括分布式存储与处理、数据采集、智能分析、交互可视化、改进方法及验证。评分为选题设计 20%、演示 30%、报告 25%、代码 25%。第16周提交 PPT、报告、代码与视频，成员贡献如实填写。具体截止日期及组员信息待课程信息补齐。

## 2 范围

正式数据为 Reporting Carrier On-Time Performance 2024年1至6月，保留全部月份数据进行统计。先单月试跑，再补齐六个月。禁止混用 Marketing Carrier 表。保存来源、UTC获取时间、SHA256、大小、月份、实际表头、行数和字段映射。

官方目录：https://www.transtats.bts.gov/PREZIP/

字段：https://www.transtats.bts.gov/Fields.asp?gnoyr_VQ=FGJ

机场坐标与底图采用可核查且允许使用的来源，保存许可证与快照。未匹配机场保留统计并披露地图覆盖率。

不增加实时航空接口、天气服务、Kafka、Flink、Hive、HBase、Kubernetes、深度学习、多年数据或用户权限系统。

## 3 数据口径

ArrDel15 表示到达延误至少15分钟。建模仅使用未取消、未备降且标签有效的记录。取消、备降、标签缺失分别统计。延误率分母为可判定到达状态的航班数；取消率分母为范围内计划航班数。平均 ArrDelay 保留提前到达负值。跨组比例通过分子分母汇总计算。

完全重复与业务键冲突分别检查。业务键包含日期、航司、航班号、起降机场、计划起飞时刻；不能只按航班号去重。关键字段异常进入隔离层并记录原因。计划时刻为机场本地时间；不将未转换的各地时刻拼成绝对时间轴。2400按规范解析，非法分钟不得直接截断。

只用计划信息作为预测输入；实际起降时间、延误分钟、取消/备降状态、延误原因均不得进入输入。取消和备降排除是条件性研究样本定义，系统不预测取消或备降风险。

## 4 架构与部署

Python采集 → HDFS raw CSV → Spark清洗 → silver Parquet → Spark聚合/特征/MLlib训练 → gold产物 → SQLite与实验文件 → FastAPI → Vue3/Vite/ECharts。

优先 WSL2 Ubuntu 独立项目运行环境，HDFS NameNode/DataNode 伪分布式＋Spark Standalone Master/Worker，均为同机进程。Spark local 用于早期调试，最终必须有 HDFS 与 Standalone 实际处理证据，不宣称多物理机集群。依赖隔离安装、版本锁定。计算与网页演示分时运行。项目数据和运行依赖放D盘，避免占满C盘。不修改其他项目的环境和系统级配置。

## 6 模型实验

1月为历史预热，2至4月统一训练，5月验证，6月测试。随机种子42。2月历史来自1月，3月来自1至2月，4月来自1至3月。5月、6月均冻结使用1至4月历史。训练编码器和数值变换只在训练期拟合。

| 组别 | 方法 |
| --- | --- |
| B0 | 分层历史率＋低样本回退 |
| B1 | Spark LogisticRegression＋基础计划特征 |
| B2 | Spark RandomForestClassifier＋相同基础特征 |
| B3 | B2＋历史机场/航司/航线延误率、支持数、缺失标记 |

历史率平滑处理。B2/B3使用相同参数候选集合及搜索预算，各自以验证PR-AUC选优，同时保存相同参数配对结果。小规模搜索一次完成，不因负面结果自动扩张。基础特征含星期、计划时刻、航司、起降机场、距离、计划耗时；不把完整日期编码为类别。

主指标PR-AUC，固定实现并标注计算口径；同时记录ROC-AUC、Precision、Recall、F1、混淆矩阵、Brier与样本数。阈值仅在验证集按F1选择并冻结。可靠性图固定分箱，报告各箱样本数。测试集不用于调参或挑选上线模型。按机场、时段、历史支持数分析误差。

判据：报告B3相对B2的实际差值及分组表现，不设必须达到的提升。结果不支持改善时如实记录。性能、机制解释与创新性分别表述。历史统计关联不作为因果解释。

## 7 工程实验

同一份清洗数据保存CSV与Parquet，固定字段、有效记录、过滤、资源、查询、显式CSV schema。比较相同月/航司/机场聚合，至少三轮交替运行，记录每轮及中位数、文件大小/数、资源、分区、缓存状态、可得扫描指标。禁用显式Spark缓存；不能清除OS缓存时注明。检查各组计数一致、浮点结果在预定容差内一致。原始文件到清洗文件的端到端耗时另列，不解释为纯格式收益。
