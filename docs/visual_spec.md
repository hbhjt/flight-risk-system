# 视觉与交互规范

四页面与数据语义遵循final_plan.md。桌面优先，1920×1080与1366×768验收。

背景#0B1220，面板#141F33，正文#E6EDF7，次要信息#9AAEC8，航线#38CFE8，风险#F6B44D。比例色阶保持跨图一致，未知风险使用灰色。气泡采用面积映射样本量，色彩映射延误率，明确图例。

页面共用月份/航司/机场筛选及数据范围条；异步查询中保留筛选可见性，防止旧响应覆盖新筛选。空态解释无匹配条件，错误态提供重试。百分比保留1位小数，样本数单独展示。样本支持不是置信度。

P1地图点击后联动趋势、排名、热力图；机场统计默认按出发机场定义。P2小时滑杆用于历史小时分组，不显示实时航班标识；仅显示Top-N示意连接，防止航线遮挡。P3显示模型版本、特征快照、样本支持、回测标识，实际标签单独展开。P4直接读取实验产物，未运行展示待运行。

本地地图素材需包含许可证与来源，非本土机场使用附图/列表，披露地图坐标覆盖率。动画只用于反馈交互，不增加虚假动态数据。
