# M3 预设实验协议

配置文件ml/experiment.json为机器可读依据，SHA256写入所有特征审计与实验产物。2026-11-16在正式拟合前确定。后续因工程错误重试不得混入不同配置，不能看测试结果后改变搜索范围。

## 问题与判据

比较B2基础计划特征随机森林与B3历史统计增强随机森林的时间外预测表现。主指标为完整PR曲线梯形积分面积，另报告Average Precision（阶梯积分），不混用名称。比较实际差值，不设必须提升的门槛。一个半年划分、一个随机种子，不做统计显著性或跨年份泛化结论。按机场、时段、航线历史支持数检查错误。

## 数据与时间

1月仅预热，2—4月训练，5月验证，6月测试。仅未取消、未备降且到达标签有效的航班进入候选；计划时刻、距离、计划耗时等无效时统一排除，记录每月损失。

2月使用1月历史；3月使用1—2月；4月使用1—3月。5月、6月都使用1—4月冻结历史。历史统计来自相应月份的全部有效到达标签，目标训练样本再应用计划特征有效性过滤。B0按训练期2—4月拟合航司×出发机场历史率，支持不足100回退出发机场、航司、全局。B0不生成训练期的拟合内性能。

机场、目的地、航司及航线历史率采用(rate positives + 100 × 同快照全局率)/(count + 100)。平滑强度100为预设常量，不搜索；增加log1p支持数及缺失标记。每行保留历史最大月份和截止月份。修改5—6月标签不得改变历史输入。

## 共同输入与编码

基础计划信息为航司、出发机场、到达机场、计划起降时刻、星期、月内日、距离、计划耗时；时刻和星期包含周期编码。完整日期和月份不作为类别输入，日期仅用于切分和日历变换。实际延误、实际起降时间、取消/备降、延误原因均不进入向量。

类别字典只在2—4月拟合，未知类别保留独立编码。LR使用one-hot和训练内部标准化；RF保留Spark标记的类别索引，避免将机场索引误当有序数值。B1与B2的表示方式不同，因此两者差异不全部解释为非线性收益。B2和B3编码一致，仅B3增加历史输入。

## 预算

- 随机种子42。
- B1正则强度0.01、0.1，L2，最多40次迭代。
- B2与B3各2组：32棵树、深度5或7；其余固定maxBins512、叶节点最小样本100、直方图内存128MB、完整训练样本bootstrap。
- 两个RF每节点都考察4个候选特征，避免sqrt规则因特征维度增加而同时改变候选特征数量。
- LR内部标准化只基于训练样本，不对全量数据拟合变换。
- 试跑使用确定性哈希约2万训练及约5千验证记录，各试1个LR和B3候选，只测耗时与执行正确性，不读取试跑性能来选参。实际样本数写入pilot.json。

正式训练6次（2个LR、2个B2、2个B3）。各组按验证PR-AUC选优；同指标选较早候选。相同RF参数的配对验证结果全部保留。分类阈值在验证集上最大化F1，精确并列选较高阈值；测试统一使用score>=threshold。选择结果写入selection.json后才运行测试。
